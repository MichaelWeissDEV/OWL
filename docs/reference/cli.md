# Command line reference

The reference below is generated from the CLI definition, so it always matches the installed
version. Common patterns:

- `-r/--remote NAME` selects a server, `--local` the local library, `--json` machine-readable output.
- `REF` arguments are `author/name` or a bare `name`.
- Commands that read data honour the mode: in client mode they default to the default remote.
